LMU Stratégie

La calculette de stratégie d'endurance de l'équipe, avec la télémétrie en direct de notre pilote.

Ouvrir la calculette Télécharger le programme pilote (Windows)
C'est quoi, en deux mots ?

Un site pour préparer et suivre la stratégie de course (relais, énergie, pneus, arrêts) et un petit programme que le pilote lance sur son PC. Le programme envoie à l'équipe ce qui se passe en piste : tout le monde le voit en direct sur le site.

Qui doit installer le programme ?

Seulement le pilote qui roule. Les ingénieurs et les pilotes qui ne sont pas en piste n'installent rien : ils ouvrent le site dans leur navigateur.

Comment j'accède au site ?
  1. Demandez à un admin de l'équipe un lien d'invitation (il précise votre rôle : admin, pilote ou lecteur).
  2. Ouvrez le lien, créez votre compte (e-mail + mot de passe) et vous arrivez dans l'équipe.
  3. Ouvrez ensuite la session de la course dans la liste.

Seuls les membres de l'équipe voient les sessions et la télémétrie.

Pilote : comment installer et lancer le programme ?
  1. Téléchargez LMU-Strategie-Connecteur.exe avec le bouton ci-dessus. Il n'y a rien à installer : double-clic.
  2. Connectez-vous avec le même e-mail et mot de passe que sur le site.
  3. Choisissez la session (ou créez-la avec « + Nouvelle session »), vérifiez votre nom, puis « Démarrer l'envoi ».
  4. Laissez la fenêtre ouverte (vous pouvez la réduire) et lancez le jeu. L'envoi démarre dès que vous roulez.

Au changement de pilote : le pilote qui sort clique sur « Arrêter », le suivant lance le programme et choisit la même session.

Windows affiche « Windows a protégé votre ordinateur ». C'est normal ?

Oui : le programme n'est pas signé numériquement, donc Windows se méfie de tout nouveau fichier. Cliquez sur « Informations complémentaires » puis « Exécuter quand même ». Votre antivirus peut aussi demander confirmation la première fois.

Que fait le programme sur mon PC ?
  • Il lit les données du jeu (en lecture seule, il ne modifie rien dans LMU).
  • Il les envoie à l'équipe, pas ailleurs.
  • Votre mot de passe n'est jamais enregistré ; vous restez simplement connecté aux lancements suivants. « Changer de compte » vous déconnecte.
Ingénieur / pilote hors piste : comment voir le pilote en direct ?
  1. Ouvrez la session de l'équipe sur le site.
  2. Allez dans Mode Live et choisissez la source « 🌐 À distance — pilote au volant ».
  3. Vous voyez la carte, le classement, les tours et la stratégie recalculée. En cas de relais, le site suit tout seul le pilote qui roule.

Les valeurs arrivent environ 2 fois par seconde. Le Mode Live à distance est en lecture seule : regarder ne modifie rien dans la session partagée.

Le pilote apparaît « hors ligne », ou le Mode Live reste vide
  • Le pilote a-t-il bien lancé le programme, choisi la même session que vous, et il est en piste (pas seulement dans les menus) ?
  • « hors ligne · 20 s » veut dire : plus aucune donnée depuis 20 secondes. Le pilote peut regarder la fenêtre du programme, qui indique l'état du jeu et de l'envoi (bouton « Journal » pour le détail).
  • Quelques secondes de retard à l'arrivée sur la piste, c'est normal.
J'ai oublié mon mot de passe, ou je n'ai pas le bon rôle

Mot de passe : utilisez « mot de passe oublié » sur la page de connexion du site. Rôle (lecteur → pilote, par exemple) : demandez à un admin de l'équipe.

Qui peut créer une session ?

Les admins et les pilotes, depuis le site (« + Nouvelle ») ou depuis la fenêtre du programme. Seuls les admins peuvent renommer ou supprimer une session.
