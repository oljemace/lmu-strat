📡 Import télémétrie Le Mans Ultimate

Une page publiée ne peut pas lire vos fichiers de jeu automatiquement (sandbox du navigateur). Ouvrez un ou plusieurs fichiers de résultats XML générés par LMU après une session (dossier Documents\Le Mans Ultimate\UserData\Log\Results\…xml, un fichier par séance, ex. 04P1.xml). Une séance multijoueur contient souvent plusieurs pilotes sur des voitures différentes, avec des pneus différents : l'outil construit un tableau — une ligne par voiture (temps au tour, VE/t, usure S/M/H/W), une colonne par pilote — et vous choisissez la cellule (pilote + voiture) à importer dans l'éditeur ci-dessus, pour le circuit (TrackVenue) détecté dans le fichier.

📟 Import télémétrie MoTeC (.ld, DAMPlugin)

Alternative au fichier de résultats XML : importez directement le fichier .ld enregistré par le plugin DAMPlugin (format MoTeC), lu tour par tour pour calculer l'usure pneus par tour (canaux Tyre Wear FL/FR/RL/RR) et la consommation par tour (canal Fuel Level), même pour les voitures GT3/LMP2 dont le fichier de résultats XML ne contient pas ces attributs. Le premier et le dernier tour du fichier (entrée/sortie des stands) sont exclus de la moyenne.

🧠 Import télémétrie JSON (shared memory LMU, temps réel)

Méthode la plus directe : exécutez le script lmu_telemetry_logger.py (fourni) sur le PC qui fait tourner LMU — il lit la shared memory du jeu en direct (plugin rF2SharedMemoryMapPlugin) et écrit un fichier JSON mis à jour à chaque tour complété (usure 4 pneus, carburant consommé, temps au tour, gommes). Importez simplement ce JSON ici, pour n'importe quelle voiture (GT3, LMP2, Hypercar…), sans dépendre du fichier de résultats XML ni d'un enregistrement MoTeC.
